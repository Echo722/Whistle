# R1 试用说明（独立桌面音效浏览器骨架）

## 1. 启动与预扫描

### 启动桌面窗口
```powershell
uv run --locked --group desktop --group playback python -m audiosearch.browser
```
也可以直接附带一个目录在启动时自动加入并扫描：
```powershell
uv run --locked --group desktop --group playback python -m audiosearch.browser --add-root samples/audio
```

### 命令行预扫描（可选）
```powershell
uv run --locked --group playback audiosearch scan samples/audio
```
数据库默认保存在 `.local/library.sqlite3`。

---

## 2. 上手流程

1. 点击顶部 **`+ 添加文件夹`**，先选 `samples/audio`（18,483 条真实样本），观察右上角扫描进度与 **`暂停扫描` / `继续扫描`**。
2. 扫完后可再挂载 `F:\` 全库测试；左侧树支持展开子目录、右键 **`重新扫描此目录`** 或 **`从库中移除`**；离线或未挂载的根盘会灰显，不丢历史索引。
3. 顶部工具栏 **`范围：当前目录` / `范围：全局搜索`** 可切换是否仅在当前选中文件夹子树内检索；`◀` / `▶` / `▲` 导航历史与上级目录。
4. 在搜索框输入关键词即时过滤，支持 ME 检索语法：
   - 空格：`AND`（如 `whoosh heavy`）
   - `OR`：或（如 `fire OR water`）
   - `NOT` 或 `-词`：排除（如 `magic -loop`）
   - `"精确短语"`：短语匹配
   - `*` 通配符：前缀 `expl*` 或任意位置 `*splash*`
5. 点击列头可排序（默认复刻 ME 10 列：名称、描述、时长、采样率、声道、位深、格式、大小、素材包、路径），列宽可拖、列顺序可拖拽重排。
6. 选中行直接拖拽可把原文件拖入 REAPER、Premiere、Resolve、剪映等时间线。

## 3. 已定键位与鼠标操作

| 操作 | 行为 |
|---|---|
| 列表 **单击** | 选中该行并从头自动播放 |
| **`↑` / `↓`** | 切换上一行 / 下一行并从头自动播放 |
| **`Space`** | 播放 / 暂停（暂停保留当前播放指针，再按从当前指针处续播；搜索框聚焦时输入空格，输入法组字不拦截） |
| **`Esc`** | 停止播放 |
| **`Ctrl+F`** | 聚焦搜索框并全选 |
| **`Alt+←` / `Alt+→`** | 文件夹浏览历史后退 / 前进 |
| 波形 **单击** | 从点击位置定位并开始播放（蓝线为审听游标，琥珀线为声卡真实帧计数播放头） |
| 列表 **拖拽 / 右键** | 拖出原文件（`CF_HDROP`）；右键打开所在目录、复制文件名或完整路径 |

注：已按确认取消 `←` / `→` 播放头微移。

## 4. 本机实测数据（2026-11-23）

### 真实样本库（`samples/audio/`，18,483 条 WAV）
- 首次全量扫描：21.59 s（新增 18,483 条，0 错误）
- 二次增量扫描（无变更跳过）：0.43 s
- 首页浏览（18,483 条）：2.45 ms
- 过滤查询：`whoosh` 3.36 ms / `fire OR water` 2.86 ms / `magic -loop` 11.11 ms / `exp*` 4.82 ms
- 列排序（时长降序）：1.38 ms
- 单文件峰值生成（1024 点）：7.47 ms；单文件本地解码：65.86 ms

### 100 万行合成库（`.local` SQLite + FTS5 实测）
- 未过滤首页浏览（1,000,000 行）：2.34 ms
- 全库切列排序（时长降序）：2.20 ms
- FTS 检索（`count + 首屏 200 行` 总耗时）：
  - 精准词（1 条命中）：0.37 ms
  - 组合 AND（10,000 条命中）：39.50 ms
  - 超大命中词（100,000–200,000 条命中，`whoosh` / `OR` / `NOT` / `imp*`）：256–267 ms（后台线程异步执行，不阻塞输入）

## 5. 请你重点验收的项目

1. 在 `samples/audio` 与 F 盘全库上：输入过滤是否跟手、超大命中词在 250ms 左右时手感是否可接受。
2. 单击、`↑`/`↓`、`Space` 暂停续播、点击波形定位的出声延迟、清晰度与防爆音表现（Focusrite Scarlett 4i4）。
3. 列表拖拽原文件到 REAPER（及剪映/视频软件）时间线是否顺畅落地。
4. 右侧检查器封面（MediaEye 链路）与内嵌描述展示是否准确。
