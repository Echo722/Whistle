# R2 试用说明（试听深化 · ME 操作复刻）

## 启动方式

在仓库根目录以普通权限 PowerShell 执行（首次同步依赖后启动）：

```powershell
cd <项目根目录>
uv sync --locked --group desktop --group playback
uv run --locked --group desktop --group playback python -m audiosearch.browser
```

## R2 新增功能与操作

### 1. 试听控制条（DAW 风格无极拖动旋钮 + 保留音高）
- **`▶/⏸` / `■`**：播放 / 暂停（保留当前指针续播）、停止并复位到 0。
- **`自动播放`（Autoplay，默认开启）**：关闭后，单击列表行或按 `↑` / `↓` 只切换检查器与波形，不自动发声；按 `Space`、点波形或建选区后再播放。
- **`循环`（Loop）**：开启后，有选区时循环播放选区 `[start, end)`，无选区时循环整条音频（支持任意长度流式无缝回绕）。
- **DAW 风格无极旋钮（`音量 -48 ~ +6 dB` / `变调 -24 ~ +24 st` / `变速 0.25x ~ 4.00x`）**：
  - **鼠标点中上下拖动**：无极顺滑调节（播放中实时生效，无需重启解码流）；
  - **按住 `Shift` 或 `Ctrl` 拖动**：`0.1x` 精度微调；
  - **滚轮**：按步长增减（配合 `Shift`/`Ctrl` 微调）；
  - **左键双击**：一键复位默认值（音量 `0.0 dB`、变调 `0.0 st`、变速 `1.00x`）；
  - **右键菜单**：复位默认值或「精确输入...」数字设定。
- **`保留音高`（Preserve Pitch）**：
  - **关闭（默认，传统 Varispeed）**：变调与变速物理联动（`+12 st` = 2 倍速且高八度），超低延迟顺滑拖动；
  - **开启**：变调与变速独立生效（纯流式 `StreamingWSOLA` 实时拉伸，改速率不变调 / 改音高不改时长）。
- **`重置`**：一键将变调归 `0.0 st`、变速归 `1.00x`。
- **`切行重置`（默认开启）**：切换试听新文件时自动重置变调/变速，避免上一条的变调设置误串到下一条素材。
- **`应用调音`（默认开启）**：拖出到 DAW 时烘焙当前变调/变速效果；双击 / 按 `Enter` Spot 插入 REAPER 时，将该变调/变速/保留音高非破坏性地写入 Take 属性（不生成临时 WAV）。

### 2. 列表交互 & 非破坏性 REAPER Spot 插入
- **单击列表行（同步 REAPER ME）**：
  - 首次点中未选中行时更新右侧检查器/底部波形并自动从头播放（开启「自动播放」时）；
  - **继续单击已选中行**（文件名、时长、描述等任意区域，不含波形绘制区）**不会重播、不会清空已有选区、不会打断播放**，可直接按住拖拽进 DAW 或右键操作；
  - 到首行再按 `↑` 或末行再按 `↓` 同理不重播；如需从头重听请按 **`Space`** 或直接点击列表/底部波形条。
- **双击列表行 / 按 `Enter`（或右键「插入到 REAPER 光标处」）**：
  - 将原文件**非破坏性直插**到当前 REAPER 工程选中轨道的编辑光标处（无选中轨则自动新建轨道），插入后光标自动顺移到 Item 末尾，支持一次 `Ctrl+Z` 撤销；
  - 若底部波形存在蓝色选区，只裁切插入该选区（`D_STARTOFFS` + `D_LENGTH`，进 REAPER 仍可左右拉边缘恢复前后余量）；
  - 状态栏最右侧实时显示 `REAPER 已连接 · <当前轨名>` / `REAPER 未连接`（可通过状态栏 REAPER 入口一键将轻量后台桥 `audiosearch_spot_bridge.lua` 写入 `<REAPER 资源目录>\Scripts\__startup.lua`，重启 REAPER 或在 REAPER Action List 运行一次该脚本即可上线）。

### 3. 波形选区、边缘微调、缩放与拖出（REAPER ME 交互）
- **建立选区并试听**：在无选区位置或选区外部按住左键横向拖拽建立选区 `[start, end)`；松手后若「自动播放」开启或当前正在播放，立即从选区起点试听该选区。
- **拖拽选区左右边缘微调**：鼠标移至选区左右边界 `6 px` 内光标变为 `↔`，按住左键拖拽实时微调 `[start, end)`（支持跨过对侧边缘反转，松手后自动试听新选区）。
- **单击与清选行为**：
  - 在**选区内部**单击（未达拖拽阈值）：保留选区并从点击处 Seek 续播；
  - 在**选区外部**单击（未达拖拽阈值）：清除现有选区并从点击处 Seek 播放；
  - **`Esc` 两段行为**：有选区时按 `Esc` 先清除选区（不停播）；无选区时按 `Esc` 停止播放。
- **拖出到 DAW**：
  - 从**选区中部**按住左键拖拽（鼠标变为手型）直接导出选中片段为临时 WAV 并拖入 REAPER / Premiere / Resolve / 剪映时间线；
  - 按住 **`Alt` 拖拽** 自动在片段首尾加 `5 ms` 淡入淡出防咔哒声；
  - 临时文件存于 `.local/renders/`，自动保留最近 50 个。
- **波形缩放、平移与右键菜单**：
  - **滚轮**：以光标位置为锚点横向放大 / 缩小（放大超过 4 倍自动加载该区间 2048 点高精度波形峰）；
  - **鼠标中键拖拽** 或 **`Ctrl + 滚轮`**：在放大视图中左右平移；
  - **双击波形**：复位到全文件视图；
  - **右键波形**：清除选区、缩放到选区、重置视图。

### 4. 列表内置波形预览 + 峰值持久化缓存 + 布局记忆
- 列表行内波形列按时长对数比例绘制缩略波形，可直接点击任意位置 Seek（即使当前行已选中也会按点击位置 Seek）；从列表行按住左键拖拽可将整条文件（开启「应用调音」且有调音变动时为烘焙版 WAV）拖入 DAW。
- 全文件波形峰与缩略图自动写入 SQLite `waveform_cache`，二次打开毫秒级出图。
- 退出自动保存窗口尺寸、分割条、列宽/列顺序、排序列、检查器、Autoplay、Loop、音量、保留音高、切行重置与应用调音设定到 `.local/browser-settings.json`。

## 本机实测数据（90.7 秒 96kHz 真实 WAV：`MACK Fire Burn Medium Blaze.wav`）
- 首次全文件峰值计算（2048 点）：`279.64 ms`；SQLite `waveform_cache` 二次命中：**`0.09 ms`**
- 放大 2 秒子区间高精度峰值计算（2048 点）：**`15.22 ms`**
- 2.5 秒选区原样导出（含 `5 ms` 淡变）：**`6.92 ms`**
- 实时流式 `StreamingWSOLA` 保留音高处理（40 ms 块）：单块耗时 **`0.5–2.0 ms`**，支持无极拖动不卡顿。

## 请你重点验收的项目
1. 拖动 **`音量` / `变调` / `变速`** 旋钮上下无极变化的手感、`Shift` 微调、双击复位与右键精确输入。
2. 播放中切换 **`保留音高`** 并拖动变调/变速时的实时连续性（无重启卡顿），以及拖出至 REAPER 时 **`拖出应用`**（含 Rubber Band 保留音高烘焙与默认 Varispeed 烘焙）的音质。
3. 波形上建立选区 → 松手即播 → 拖左右边缘 `↔` 微调 → 选区内单击 Seek → 选区中部拖出到 REAPER → 选区外单击清选，以及中键平移 / 右键菜单。
4. 开启 **`切行重置`** 时切歌是否自动归零变调/变速，关闭时是否保留设定。
